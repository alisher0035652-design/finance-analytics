# Финансовая аналитика (Excel на Google Диске + Render)

Этот проект скачивает оригинальный `.xlsx` файл с формулами прямо с Google Диска через сервисный аккаунт и отображает дашборд на Render.

## Инструкция по настройке:
1. Дайте доступ к вашему файлу `Финансы.xlsx` на Google Диске на **email сервисного аккаунта** (`client_email` из вашего JSON-ключа), выдав ему права «Читатель».
2. Загрузите в ваш репозиторий GitHub:
   - `app.py`
   - `requirements.txt`
   - Ваш файл ключа под именем `credentials.json`
3. Настройте деплой на Render.
